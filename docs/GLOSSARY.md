# Glossary

Short terms used in this repo. The scaffold has its own glossary in `templates/base/docs/GLOSSARY.md`.

- `PM`: Product Manager, the human who defines and confirms scope.
- `US`: User Story, `As a X, I want Y, so I can Z`.
- `AC`: Acceptance Criterion of a US (Given/When/Then), identified as `ACn.m`.
- `Epic`: a larger unit of work that groups related user stories. One epic per sprint.
- `Producer`: the main agent session, which writes specs, code and docs.
- `Reviewer` / judge: an independent, read-only agent with a fresh context.
- `Adapter`: a thin, generated platform file (slash command, agent, hook) that points to the skills.
- `Catalog`: a file of stack-specific audit rules used by the reviewer.
